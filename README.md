   Calculator Web App

A responsive and interactive Calculator Web Application built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations with a clean and intuitive user interface, demonstrating JavaScript event handling, DOM manipulation, and expression evaluation.

Features : 

-  Addition opertaion
-  Subtraction opertaion
-  Multiplication opertaion
-  Division opertaion
-  Clear all input
-  Delete the last entered character
-  Instant calculation and result display
-  Fully responsive design for desktop and mobile devices

 Tech Stack Used : 

- HTML5
- CSS3
- JavaScript

Source Code : https://github.com/AlokeShaw1234/Calculator

Live Demo : https://calculator-one-red-40.vercel.app/
